# Planet Wars Rules

Players conquer planets and launch ships across a star map. Every player sees the whole board: there is no camera, no scrolling and no fog.

## Controls

The mouse drives everything. Click one of your own planets to select it, shift-click to add more, and double-click to select everything you own. Click any other planet to launch a wave at it from every selected planet. The selection survives the send, so clicking a second target sends again.

The number keys set what share of a planet each wave launches: 1 for 10% through 9 for 90%, and 0 for everything. Waves start at half. A planet never sends its last ship, so a send can never leave one undefended.

## Combat

A wave spawns in rings around the planet circumference and fans out, each ship steering on its own heading. Ships from the same player push each other apart; ships from different players pass straight through. Arriving ships fight the garrison one for one, and the planet flips when the attackers outnumber it.

## Winning

Neutral planets never regrow, so an uncaptured planet is a fixed price. Owned planets grow a ship every interval, which makes early captures compound. Score accrues every second as the square of the planets you hold, so holding twelve planets scores four times as fast as holding six.

A player wins when every remaining planet and ship belongs to them. If the tick limit is reached first, the game ends with no winner and the scores stand.
