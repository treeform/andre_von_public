Global spectators connect a websocket to /global and receive the full snapshot as JSON after every event: {"type":"state","game":"cogplomacy","seats":[{power,name,centres,units,score,pending,eliminated,stabbedThisTurn,broadcast,lettersOut,pledges,notes} x7 by SEAT],"seatOfPower":[7],"units":[{power,kind,province,coast,dislodged}],"owners":[{centre,power} x34],"arrows":[{kind:move|support|convoy,from,to,aux,power,outcome:success|bounce|void|noconvoy|cut|dislodged}],"stabs":[{power,pledgeTo,kind,order}],"standoffs":[province codes],"year":int,"season":str,"phase":str,"years":int,"yearsPlayed":int,"counts":[per-year centre counts],"press":[{from,to,text,public}],"gameDone":bool,"reason":str,"soloist":str,"policyNames":[7],"events":[...],"started":bool,"done":bool,"connected":[bool]}. The events array is append-only and carries the complete transcript in nine kinds - start, phase, press, orders, adjudicate, retreat, build, centres, end - INCLUDING every private letter and every pledge: spectators read all the correspondence, which is the whole point of watching Diplomacy. The browser page at /client/global renders the map live; /client/replay plays a recorded episode; the static replay viewer bundle renders replays hosted by the platform (index.html?replay=<url>) by re-deriving every frame from the recorded events with the same Nim adjudicator the server ran.
