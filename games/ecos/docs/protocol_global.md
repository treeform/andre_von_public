Global spectators connect a websocket to /global and receive the bitworld sprite protocol as binary frames: a layer + viewport message, the sprite definitions (soil tiles, four grass stages, the grazer and predator poses, the sparkle/splash/fade effects and the silent-spring wash), then one object message per living body per frame with stale ids deleted. The broadcast chrome - scorebug, GEN n / 10 clock, doctrine feed, transport, population strip and end-card - rides as the LABEL of the reserved 1x1 sprite id 4090 and is routed straight to the page's onText handler; it is a JSON object with t/mt/ph/pl/sp/mx/st/teams/roster/events, plus lead (the whole-episode population strip, shipped once) and over (the end-card).

GET /client/global serves that page live. Recorded episodes are NOT served by a pod: the replay is one strict-UTF-8 JSON document (protocol ecos.replay.v1) of per-tick state frames, and the static wasm bundle plays it at index.html?replay=<url>. GET /healthz and GET /client/player?slot=N&token=T complete the contract.
