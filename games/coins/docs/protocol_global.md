WS /global is the live spectator channel: paintbot's binary sprite protocol for the board (layer + viewport + sprite definitions + retained-mode object placements over a 504x504 zoomable map layer) with the broadcast chrome smuggled as the LABEL of the reserved 1x1 sprite id 4090, which client/broadcast_core.js routes to onText and never draws. The chrome frame carries t, mt, ph, pl, sp, mx, st, lp, sk, ff, en, mm, bs, pov, teams, roster, events, lead, beats, lulls, over, hold — the key set client/chrome_common.js consumes unmodified — plus one game key, cn, holding the beat, the reciprocity rows, the truce beats, the coins on the board, the theft counters and the index summary.

GET /client/global serves the same page the static bundle serves. GET /healthz answers 200 from process start until shutdownGraceSeconds after the artifacts are written, and /global keeps answering (including WebSocket Ping with Pong) for that same grace, because hosted certification pings it AFTER the player pods start.

Replays are a STATIC file plus a browser wasm viewer, never a pod: the bundle is index.html?replay=<url of the .replay file>. The viewer re-derives every frame from the replay bytes alone (aliases, policy names, colours, the variant, the whole config, the seed, the room, per-tick state frames, both series, the index summary, every event and the full results object are all in the file); no server is contacted except S3 for the replay.
