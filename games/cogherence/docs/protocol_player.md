Connect to the game's `/player?slot=&token=` route (the runner injects the URL as COWORLD_PLAYER_WS_URL; a bad slot/token gets 401). Frames are JSON over the shared @cogweb/coworld player protocol: on `welcome` record your slot + public config; on each `observation` return a `reply` whose `decision` is `{ orders: [...] }` — an Order is one of `{type:'align',tile,force}`, `{type:'exploit',tile}`, `{type:'abandon',tile}`, `{type:'transfer',to,mineral,amount}`, `{type:'bid',energy}`; an empty list holds. The host validates legality and, on rejection, re-requests with a `reason`. On `final` the episode is over.
