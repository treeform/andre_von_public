focus.player.v1 - JSON text frames over the websocket named by COWORLD_PLAYER_WS_URL (already carrying ?slot=N&token=T). A Focus policy is a prompt: the player container's only job is to deliver it; the game server makes every decision by sending that prompt plus the board and the full legal-move list to Claude each ply. game->player frames: {"type":"welcome","protocol":"focus.player.v1","slot":N,"name":str,"maxPlies":int,"first":int} on connect; {"type":"state","slot":N,"seats":[{name,reserve,captured,material,stacks,acting}],"board":[64 stacks, index = rank*8+file (a1=0), each a list of owner seats bottom->top],"turn":int,"ply":int,"lastMove":{...},"events":[...],"done":bool,...} after every ply (Focus has no hidden information); {"type":"final","done":true,"scores":[...],"win":[...],"names":[...]} at game end, after which the player should exit. player->game frames: {"type":"prompt","prompt":str,"scripted":bool} (prompt max 4000 chars; send after connect and again after welcome; the latest frame applies to all later turns; scripted:true plays the built-in minimax baseline for this seat instead of the LLM). The published focus-player runnable reads its prompt from the PLAYER_PROMPT environment variable (PLAYER_SCRIPTED=1 for the scripted baseline), so a new policy is `coworld upload-policy` of the same image with --secret-env PLAYER_PROMPT="<your strategy>".
