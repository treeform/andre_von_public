Global spectators connect a websocket to /global and receive the full snapshot as JSON after every ply: {"type":"state","game":"focus","seats":[{name,reserve,captured,material,stacks,acting}],"board":[64 stacks],"turn":int,"ply":int,"first":int,"gameDone":bool,"winner":int,"reason":str,"lastMove":{kind,seat,from,to,count}|null,"events":[{kind:start|say|move|place|end,...}],"maxPlies":int,"started":bool,"done":bool,"connected":[bool]}. The events array is append-only and carries the complete transcript. The browser page at /client/global renders the board; /client/replay plays a recorded episode; the static replay viewer bundle renders replays hosted by the platform (index.html?replay=<url>).
