lighthouse.player.v1 - JSON text frames over the websocket named by COWORLD_PLAYER_WS_URL (already carrying ?slot=N&token=T). A Lighthouse policy is a prompt: the player container's only job is to deliver it; the game server makes every decision by sending that prompt plus the seat's observation to Claude, all active seats in ONE parallel batch per tick. Slot 0 is the KEEPER, slots 1-3 are RUNNERS. game->player frames: {"type":"welcome","protocol":"lighthouse.player.v1","slot":N,"name":str,"role":"keeper"|"runner","maxTicks":int} on connect; {"type":"state","slot":N,"name":str,"role":str,"seat":{"status":str,"keys":int,"lastMove":str,"blocked":bool,"messages":int},"tick":int,"maxTicks":int,"keysCollected":int,"keyCount":int,"gateOpen":bool,"escaped":int,"drowned":int,"teamScore":float,"started":bool,"done":bool,"reason":str} after every tick - REDACTED, because hidden information is the whole game: a runner's frame never carries the grid, any coordinates or the tide, and the keeper's frame never carries a runner's notes. Decisions are server-side so nothing is lost; {"type":"final","done":true,"scores":[4],"roles":[4],"names":[4 aliases],"keys":int,"escaped":int,"drowned":int,"ticks":int,"reason":str} at episode end, after which the player should exit - the final frame carries the anonymous ALIASES, only results.json carries policy names. player->game frames: {"type":"prompt","prompt":str,"scripted":str} (prompt max 4000 chars; send after connect and again after welcome; the latest frame applies to all later ticks). `scripted` is "" for the LLM policy, "lantern" for the scripted keeper baseline, "wallhug" for the scripted runner baseline, or "1"/"true"/"yes" for whichever of the two the dealt slot needs - a baseline dealt the wrong slot always plays the other one rather than stranding the episode. The published lighthouse-player runnable reads its prompt from the PLAYER_PROMPT environment variable (PLAYER_SCRIPTED for the baselines), so a new policy is `coworld upload-policy` of the same image with --secret-env PLAYER_PROMPT="<your strategy>".
