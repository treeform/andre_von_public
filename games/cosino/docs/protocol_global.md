Global spectators connect a websocket to /global and receive the full snapshot as JSON after every decision: {"type":"state","game":"cosino","seats":[{name,stack,bet,net,cards,revealed,folded,allIn,acting,handsWon}],"board":[ints],"pot":int,"street":str,"hand":int,"pair":int,"mirror":bool,"button":int,"currentBet":int,"config":{variant,chipRace,seats,startingStack,ante,smallBlind,bigBlind,bets,maxWagers,hands,duplicate,seatOrder,seed,gameVersion},"events":[...],"handsPlayed":int,"hands":int,"started":bool,"done":bool,"connected":[bool]}. Event kinds: handStart (carries pair, mirror and data.positions), deal, ante, blind, say, action, board, reveal, award, stackOff, bust (chip race only: the seat is out for good), handEnd (data.net per slot), handVoid (data.refunds), calib (per-seat exploitability, calibration rungs only), audit (one per flagged pair at six-max) and matchEnd (data.reason/handsScored/seed/audit, always last). SPECTATORS SEE EVERY HOLE CARD - that is the spectator's edge. The browser page at /client/global renders the table; the static replay-viewer bundle renders hosted replays (index.html?replay=<url>) with no server in the loop at all.
