JSON WebSocket protocol. Complete state arrives in game_start and turn_start. Decision requests are action_request (or one action_repair_request), proposal_request, debate_request, and vote_request; echo rid. Actions are natural-language strings. Proposal kinds are enact|amend|repeal|transmute. Debate replies contain text and private vote_intent. Vote replies contain vote aye|nay and reason. Missing/malformed actions pass; missing/malformed votes are NAY. See repository docs/player_protocol.md.
