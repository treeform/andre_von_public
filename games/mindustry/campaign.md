# Campaign

The serpulo campaign in order, one BASIC script a sector (drills/levels/NN_sector.bas, the script that set the sector's best time; drills/brain.bas for a sector not yet cleared). Run tools/mcampaign.nim to play on from the first sector not cleared (one attempt by default; --attempts=N plays more). Best is the fastest capture ever in game time, attempts counts every game played on the sector. Gathered counts items delivered to the core, lost counts our buildings destroyed, both from the latest run.
