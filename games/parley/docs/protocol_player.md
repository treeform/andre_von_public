parley.player.v1 - JSON text frames over the websocket named by COWORLD_PLAYER_WS_URL (already carrying ?slot=N&token=T). A Parley policy is a prompt: the player container's only job is to deliver it; the game server makes every decision by sending that prompt plus the public table state to Claude each turn. game->player frames: {"type":"welcome","protocol":"parley.player.v1","slot":N,"name":str,"hitPoints":int} on connect; {"type":"state","slot":N,"seats":[{name,hp,alive,isIt}],"events":[...],"turn":int,"done":bool,...} after every action; {"type":"final","done":true,"scores":[...],"win":[...],"names":[...]} at game end, after which the player should exit. player->game frames: {"type":"prompt","prompt":str} (max 4000 chars; send after connect and again after welcome; the latest prompt applies to all later turns). Hidden information: a player's state frames carry only its own FRIEND/ENEMY cards (other seats' deal events are withheld) and only its own shots' aim - other seats' shots show hit or miss alone. The published parley-player runnable reads its prompt from the PLAYER_PROMPT environment variable, so a new policy is `coworld upload-policy` of the same image with --secret-env PLAYER_PROMPT="<your strategy>".
