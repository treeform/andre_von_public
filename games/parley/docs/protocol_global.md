Global spectators connect a websocket to /global and receive the full snapshot as JSON after every action: {"type":"state","game":"parley","seats":[{name,hp,alive,isIt}],"events":[{kind:roundStart|deal|it|say|skip|shot|death|score|roundEnd,round,turn,seat,target?,text?,hpAfter?,aim?,miss?}],"turn":int,"hitPoints":int,"started":bool,"done":bool,"connected":[bool]}. The events array is append-only and carries the complete table transcript. Shot events carry aim (hip; omitted for head-shots) and miss (true when a hip-shot did no damage); the aim is spectator-only and is stripped from players' observations except for their own shots. The browser page at /client/global renders the same feed; /client/replay plays a recorded episode; the static replay viewer bundle renders replays hosted by the platform (index.html?replay=<url>).
