Global spectators connect a websocket to /global and receive the full snapshot as JSON after every event: {"type":"state","game":"tribunal","case":{"title","accused","charge","brief","suspects"[4]},"seats":[{name,role,roleId,juryIndex,score,handCount,held,introduced,argument,whisper,lean,vote|null,voteReason,notes,pending,scripted} x5 by seat],"roleSeat":{"prosecutor":seat,"defender":seat,"jurors":[3 seats]},"record":[{id,side,seat,round,kind,strength,points,text} in introduction order],"transcript":[{round,side,seat,name,text}],"whispers":[{round,juror,seat,name,text,lean}],"tally":{"guilt","innocence","guiltCards","innocenceCards"},"round":int,"rounds":int,"roundsPlayed":int,"phase":"argument|ballot|verdict|done","votes":[3],"sealed":bool,"verdict":str,"truth":str,"culprit":str,"correctJurors":int,"gameDone":bool,"reason":str,"policyNames":[...],"events":[{kind:start|round|argue|whisper|vote|verdict|end,...}],"started":bool,"done":bool,"connected":[bool]}. JURY VOTES ARE SEALED IN THE SNAPSHOT: on every frame before the verdict frame "votes" is [null,null,null], "sealed" is true and "truth"/"culprit" are empty; they fill in on the verdict frame and only then. Roles are 0 Prosecutor, 1 Defender, 2 Juror; sides are 0 prosecution, 1 defence. The events array is append-only and carries the complete transcript. The browser page at /client/global renders the courtroom live; /client/replay plays a recorded episode; and the STATIC replay-viewer bundle (a wasm build of the same Nim sim plus the same renderer) renders replays hosted by the platform as index.html?replay=<url> - there is no replay pod.
