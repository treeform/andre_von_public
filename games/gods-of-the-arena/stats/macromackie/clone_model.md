# macromackie behaviour clone: CART trees

Generated by `clone_tree.nim` from `clone_features.nim` rows. All numbers below are on held-out games unless marked otherwise.

## Summary

The depth-9 primary-order tree predicts macromackie's order class on 77.3% of test rows. The test set is 24 held-out games and 166,228 order ticks. The v275 rule set, approximated from the same features, gets 44.7%.

Most of the gap is three behaviours v275 does not have. In each, v275 would attack-move to the god:

| macromackie does instead | Share of test rows |
|---|---|
| Walks to a hold spot or waypoint (WALK_MOVE) | 9.1% |
| Stands still or stutters (WALK_STEP) | 6.6% |
| Attack-moves to the map centre or a lane corner (ATTACKMOVE_OTHER) | 5.4% |

### The rules the trees and tables point to

1. **It holds still while hurt. This is new and v275 has no equivalent.**
   - 74.7k orders, 9.6% of all orders, are a `walkTo` onto the hero's own spot. They repeat every 6 ticks with no target and no enemy in range.
   - When idle away from towers, the order depends on HP (table under "Idle decisions by health"):

     | HP | Most common order |
     |---|---|
     | under 0.2 | walk home, 58–68% |
     | 0.3 to 0.6 | hold, 65% |
     | 0.7 and up | advance |

   - Holds of 2 s or more start at HP 0.35 on average and end with an advance at about HP 0.6–0.65.
   - 42% of hold orders are issued while a heal potion is running (`healCd > 0`, the 10 s heal-over-time). Damage cancels that heal, and standing still out of combat protects it.
   - v275 keeps advancing at any HP. It only turns home when it has no heals left and HP is under 0.25.
2. **It travels with `walkTo`, not attack-move.**
   - 40k walks longer than 10 tiles go to fixed waypoints, re-issued every 48 ticks (2 s).
   - Mid waypoints, in the Red frame: (62, 46) and (66, 42).
   - Late game (minutes 12–17), the waypoints ring the enemy base: (42, 106), (18, 106), (22, 98), (26, 110).
   - Attack-moves that do not target the god go to three places:
     - the pack's lane corner (106, 106), early, median 0:36
     - the map centre (58, 58), median minute 8.5
     - the solo's corner (10, 10)
3. **It stutter-steps.**
   - When `atkCd >= 30` (a hit just landed) and it has a target, the order is WALK_STEP 99.9% of the time (n = 38.8k).
4. **It holds the tower edge.**
   - Within 1 tile of the reach line (`twMargin <= 1`), with no fresh hit and creeps that cannot absorb one tower shot, it walks home 86% of the time (n = 49k).
   - Deep inside reach (`twMargin <= -1.5`) on the tick after a hit, it attacks the tower 98% of the time.
5. **It casts W, then E, then R.**
   - E is cast once W is on cooldown (`wCd > 11`), between swings (`atkCd <= 12`), with the target within 7.1 tiles: 82%.
   - R follows a fresh E (`eCd > 192`) with the target within 6.6 tiles: 92%.
   - W goes on a hero when one is within 7.25 tiles (96%), otherwise on a creep.
6. **Targets.**
   - Heroes: it picks the lowest-HP hero 95.7% of the time (tree 96.9%).
   - Creeps: it picks the nearest, breaking ties by lowest HP. The tree gets 85.2%, nearest-creep alone 79.9%.
7. **Items.**
   - Gear order: dagger at 0:00, armor once gold > 155, Rune Crossbow at > 175, then boots.
   - It stocks heals up to 5, then buys a portal scroll.
   - A free slot gets a mana potion.
   - The buy tree is 92.4% accurate.
8. **Buyback.** It buys back on the first dead tick whenever gold >= price: 1603 of 1603 deaths. It does not buy back at any other time, apart from 4 late cases.

### Caveats

- Rows exist only on ticks with at least one order, so "no order this tick" is not modelled. The cast trees are conditional on the hero acting that tick.
- The primary tree hardly predicts CAST_Q, CAST_R, LEVEL or USE_ITEM. Use the cast trees, the level order W, E, W, E, W, R, W, E, E, Q, Q, R, and the potion rule (drink when missing at least 120 HP) for those.
- The mirror games are nearly symmetric, so they count half in training.

## 6. Feature dictionary

All features are computed in the hero's decision frame: the tick the order was issued, after vision is rebuilt, before any of that tick's orders apply, from `self.*`, `match.*`, `map.*`, `abilities()`, `items()`, `spells()` and the visibility-filtered `objects()` (an object's `targetId` reads 0 when its target is not visible to us). Distances are planar, in tiles (BASIC coordinates; 1 tile = 60000 world units). Lane corners and gods in BASIC coordinates: lane 0 corner (12, 11), lane 2 corner (103, 104), Red god (104.6, 10.4), Blue god (10.4, 104.6).

| Feature | How to compute it in BASIC |
|---|---|
| `minute` | match.battleTick / 1440 (battle minutes; TickRate 24). |
| `team` | self.team (0 Red, 1 Blue). |
| `ordinal` | Number of players(i) with players(i).team = self.team and players(i).id < self.id (0-4). |
| `alive` | self.alive (1 alive, 0 dead or dying). |
| `hp` | self.hp. |
| `hpFrac` | self.hp / self.maxHp. |
| `mana` | self.mana. |
| `manaFrac` | self.mana / self.maxMana. |
| `level` | self.level. |
| `gold` | self.gold. |
| `atkDmg` | self.attackDamage (19 + 12 x (level - 1) + item damage). |
| `atkCd` | self.attackCooldownTicks (ticks until the next basic hit lands; 13 = idle windup, up to 30 after a hit). |
| `respawn` | self.respawnTicks (0 while alive). |
| `buybackPrice` | self.buybackPrice (0 while alive; 100 x deaths while dead). |
| `canShop` | self.canShop. |
| `inSpawn` | self.inOwnSpawn. |
| `hasMove` | self.hasMoveTarget. |
| `curTgtKind` | Kind of self.targetId looked up in objects(): 0 none, 1 enemy lane creep (kind 3), 2 enemy hero (kind 2), 3 tower (kind 4), 4 neutral (kind 6), 5 other or not visible. |
| `curTgtHpFrac` | objects(t).hp / objects(t).maxHp of self.targetId, 0 if none. |
| `curTgtDist` | Tiles from self.position to the current target, 99 if none. |
| `justHit` | 1 when self.attacksLanded is larger than on the previous tick (program memory, read every tick). |
| `sinceHit` | Ticks since self.attacksLanded last increased (program memory, capped 9999). |
| `sinceOrder` | Ticks since this hero last issued any order (program memory, capped 9999). |
| `prevLabel` | Class index of this hero's previous primary order (program memory; -1 none; indices as in the label list). |
| `stunned` | self.controls.stunTicks. |
| `rooted` | self.controls.rootTicks. |
| `channel` | self.channelTicks (portal channel). |

### Labels

The primary order of a tick is chosen in this order: BUYBACK, PORTAL, the last movement or attack order (walk, attack, attack-move), the first cast, USE_ITEM, BUY, LEVEL. Casts issued together with a movement order are modelled by the per-slot cast trees.

| Label | Definition |
|---|---|
| ATTACKMOVE_GOD | attackMove whose point is within 3 tiles of the enemy god centre. |
| ATTACKMOVE_OTHER | Any other attackMove (lane corners (12, 11) / (103, 104), the map centre (57.5, 57.5), points near the enemy base). |
| WALK_HOME | walkTo more than 20 tiles away whose point is closer to our god than we are (macromackie: its spawn tile in over 90% of cases). |
| WALK_MOVE | Any other walkTo longer than 2 tiles (hold spots near a corner or tower edge). |
| WALK_STEP | walkTo of 2 tiles or less (stutter steps, R dodges, standing in spawn). |
| ATTACK_CREEP / ATTACK_HERO / ATTACK_TOWER | attackTarget on an enemy lane creep / enemy hero / tower. |
| ATTACK_OTHER | attackTarget on a barracks, the god, a neutral or an own unit. |
| CAST_Q/W/E/R | castTarget or castPoint by slot 0-3. |
| PORTAL | useItemAt with a Portal Scroll slot. |
| USE_ITEM, BUY, LEVEL, BUYBACK | useItem, buy, levelAbility, buyback. |

prevLabel uses these indices: 0 ATTACKMOVE_GOD, 1 ATTACKMOVE_OTHER, 2 WALK_HOME, 3 WALK_STEP, 4 ATTACK_CREEP, 5 ATTACK_HERO, 6 ATTACK_TOWER, 7 ATTACK_OTHER, 8 CAST_Q, 9 CAST_W, 10 CAST_E, 11 CAST_R, 12 BUY, 13 USE_ITEM, 14 PORTAL, 15 LEVEL, 16 BUYBACK, 17 WALK_MOVE.
