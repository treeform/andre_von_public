Global spectators connect a websocket to /global and receive the full snapshot as JSON after every event: {"type":"state","game":"cogiavelli","seats":[{power,name,cities,units,ducats,score,pending,eliminated,paralysed,stabbedThisTurn,spentTotal,receivedTotal,broadcast,lettersOut,pledges,notes} x6 by seat],"seatOfPower":[6],"units":[{power,kind,province,dislodged,bought}],"owners":[{city,power} x24],"arrows":[{kind,from,to,aux,power,outcome}],"purses":[{from,to,kind,amount,outcome}],"daggers":[{from,target,amount,d1,d2,roll,success}],"gifts":[{from,to,amount}],"famine":[codes],"plague":code,"rebellions":[{city,power,roll}],"stabs":[{power,pledgeTo,kind,order}],"standoffs":[codes],"year":int,"season":str,"phase":str,"years":int,"yearsPlayed":int,"counts":[[6]],"treasuries":[[6]],"press":[{from,to,text,public}],"gameDone":bool,"reason":str,"conqueror":str,"policyNames":[6],"events":[...],"started":bool,"done":bool,"connected":[bool]}. The events array is append-only and carries the complete transcript in thirteen flat kinds - start, season, famine, press, orders, spend, assassin, bribe, battle, cities, plague, winter, end - INCLUDING every private letter, every pledge, every ledger entry and every shock draw, because the spectator name space sees everything the seats do not. Each event also carries the seeded draw that produced it (famine.provinces, assassin.d1/d2/roll, plague.province, winter.rebellions[].roll, winter.incomeDraws), so the dice can be checked against the outcome. The browser page at /client/global renders the live board; /client/replay plays a recorded episode; the static replay viewer bundle renders replays hosted by the platform (index.html?replay=<url>).
