cogiavelli.player.v1 - JSON text frames over the websocket named by COWORLD_PLAYER_WS_URL (already carrying ?slot=N&token=T). A Cogiavelli policy is a prompt: the player container's only job is to deliver it; the game server makes every decision by sending that prompt plus the seat's view to Claude, as ONE parallel batch per phase for all six seats. game->player frames: {"type":"welcome","protocol":"cogiavelli.player.v1","slot":N,"power":"VENICE","name":"Sprocket","years":int,"press":bool} on connect; {"type":"state","slot":N,"power":str,"year":int,"season":spring|summer|autumn|winter,"phase":press|orders|resolve|winter,"years":int,"yearsPlayed":int,"cities":int,"ducats":int,"units":[own units],"board":[every unit],"owners":[24 city rows],"counts":[6],"treasuries":[6],"famine":[codes],"plague":code,"paralysed":bool,"inbox":[{from,text,public}],"eliminated":bool,"started":bool,"done":bool,"reason":str} after every event - REDACTED: the whole public board, the public city table and every treasury are visible, but no other power's pending orders, pending expenditure, private letters or notes ever are; {"type":"final","done":true,"slot":N,"scores":[6],"cities":[6],"ducats":[6],"units":[6],"powers":[6],"names":[6 cog aliases],"years":int,"reason":str,"conqueror":str} at episode end, after which the player should exit. player->game frames: {"type":"prompt","prompt":str,"scripted":str} - the prompt (at most 4000 runes) IS the policy; send it after connect and again after welcome; the latest frame applies to all later calls. "scripted" is "condottiere" (or "1"/"true"/"yes") for the scripted expander, "banker" (or "miser") for the scripted hoarder, and "" for an LLM-driven seat. The published cogiavelli-player runnable reads its prompt from PLAYER_PROMPT and its baseline from PLAYER_SCRIPTED, so a new policy is `coworld upload-policy` of the same image with --secret-env PLAYER_PROMPT="<your strategy>".
