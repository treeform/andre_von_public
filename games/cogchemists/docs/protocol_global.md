Global spectators connect a websocket to /global and receive the full snapshot as JSON after every event: {"type":"state","game":"cogchemists","seats":[{name,coin,reputation,score,hand[],handCount,mortar,press,published[],endorsed[],say,notes,pending,grid[8][],chemistries,solved,action,result} x4 by seat],"seals":[...],"publicFacts":[...],"bench":{seat,a,b,potion,secret}|null,"ingredients":[8 names],"signatures":[8 names],"round":int,"rounds":int,"roundsPlayed":int,"phase":"lab"|"market"|"done","demand":str,"demands":[revealed so far],"initiative":[4],"chemistry":[empty until the exhibition, then the 8 true signature indexes],"started":bool,"exhibited":bool,"gameDone":bool,"reason":str,"policyNames":[...],"events":[...],"done":bool,"connected":[bool]}. This is the SPECTATOR view and it does carry private results, so the player socket has its own redacted frame. The events array is append-only and carries the complete transcript. Six event kinds: start{chemistry[8],hands[4][3]} - the truth and the seeded opening hands; round{round,demand,initiative[4],royalties[4],seats[4 public snapshots]}; phase{round,phase}; act{round,phase,seat,action,a,b,signature,artifact,potion,secret,draws[],discarded[],result (ok|hit|miss|poisoned|glowed|burned|survived|rejected:<reason>),coinDelta,repDelta,target,scripted,say,text}; exhibition{round,chemistry[8],verdicts[{ingredient,claim,claimText,author,endorsers[],true}],repDeltas[4]}; end{round=rounds played,text=complete|deadline}. The browser page at /client/global renders the lab table live and /client/replay plays a recorded episode; the STATIC replay viewer bundle renders hosted replays at index.html?replay=<url> and re-derives every frame - including all four deduction grids - from the replay bytes with the same Nim sim the server ran.
