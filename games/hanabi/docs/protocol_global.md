Global spectators connect a websocket to /global and receive the full snapshot as JSON after every move - spectators see EVERY hand, which no seat ever does: {"type":"state","game":"hanabi","seats":[{name,seat,color,acting,hand:[{colour,rank,hintColour,hintRank,negColours,negRanks,knownPlayable,knownDead,chop,candidates,hintedTurn}],plays,misplays,discards,hints,contribution,banner,origin,fallbacks} x4],"fireworks":[5 stack heights in deck order red,yellow,green,blue,white],"discards":[{colour,rank,count}],"hintTokens":int,"maxHintTokens":8,"fuses":int,"maxFuses":3,"deck":int,"countdown":int,"turn":int,"maxTurns":int,"actor":int,"score":int,"move":<the move event that produced this state|null>,"log":[str],"phase":turn|done,"gameDone":bool,"reason":str,"endReason":str,"policyNames":[...],"events":[...],"started":bool,"done":bool,"connected":[bool]}. The events array is append-only and carries the whole transcript in exactly three kinds: start (seed, seats, handSize, maxTurns), move (one per turn: seat, action play|discard|hint, slot and the revealed card, or target/hintType/hintValue/touched/untouched plus the annotation learned/nowPlayable/nowDead/nowCritical, then hintTokens/fuses/deck/countdown/score, origin llm|retry|fallback|scripted, the seat's note and its spectator-only banner) and end (turn, text complete|deadline, endReason, score, fireworks, digest). Per-turn state is NOT stored: the static replay bundle re-derives every frame from the seed and the moves with the same Nim rules the server runs, and checks the FNV-1a digest. The browser page at /client/global renders the table live; the static replay viewer bundle renders recorded episodes (index.html?replay=<url>).
