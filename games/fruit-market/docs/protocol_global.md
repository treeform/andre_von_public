WS /global carries the bitworld sprite protocol: layer + viewport definitions, snappy-compressed RGBA sprite definitions and per-frame object placements for the 1536 x 864 board, plus the broadcast chrome smuggled as the LABEL of the reserved 1x1 sprite id 4090. The chrome frame is one JSON object per presentation frame: t, mt, ph, pl, sp, mx, st, lp, en, bs, teams{apple,banana}, roster[8] (alias in `name`, POLICY name in `pol`), events[], and -- once, on the first frame -- lead (the exchange-rate series), beats (round, firsttrade, starve, famine, gameover) and over (the verdict). GET /client/global serves that page.

Replays are a STATIC FILE plus a browser wasm viewer, never a pod: index.html?replay=<s3 url> out of the static-replay-viewer bundle decodes the recorded state frames in the browser and contacts no server but S3.
