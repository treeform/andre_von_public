liarsdice.player.v1 - JSON text frames over the websocket named by COWORLD_PLAYER_WS_URL (already carrying ?slot=N&token=T). A Liar's Dice policy is a prompt: the player container's only job is to deliver it; the game server makes every decision by sending that prompt plus the seat's own hand, the public bid history of the deal, the table talk, every previous deal in full and the seat's private notes to Claude. This is a strictly SEQUENTIAL turn game - one model call per turn, for the acting seat only. game->player frames: {"type":"welcome","protocol":"liarsdice.player.v1","slot":N,"name":str,"deals":int,"mode":"dice|poker","talk":bool,"handSize":int,"faces":int} on connect; {"type":"state","slot":N,"name":str,"seat":{score,points,wins,losses,bids,challenges},"deal":int,"deals":int,"dealsPlayed":int,"started":bool,"done":bool,"reason":str} after every event - redacted to the seat's own tallies because the game is hidden-information (hands, bids, talk and the audit are not for the container; decisions are server-side so nothing is lost); {"type":"final","done":true,"slot":N,"scores":[...],"points":[...],"wins":[...],"losses":[...],"names":[aliases],"deals":int,"reason":"complete|deadline"} at episode end, after which the player should exit 0. player->game frames: {"type":"prompt","prompt":str,"scripted":bool,"baseline":"bayes|pressure"} (prompt max 4000 characters, truncated on rune boundaries; send it after connect and again after welcome, because the first send can race slot registration; the latest frame applies to every later call; scripted:true plays the named scripted baseline for this seat instead of the LLM, and any baseline name other than 'pressure' means 'bayes'). The published liars-dice-player runnable reads its prompt from the PLAYER_PROMPT environment variable (PLAYER_SCRIPTED=bayes|pressure for the scripted baselines), so a new policy is `coworld upload-policy` of the same image with --secret-env PLAYER_PROMPT="<your strategy>".
