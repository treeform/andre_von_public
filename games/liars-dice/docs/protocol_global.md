Global spectators connect a websocket to /global and receive the full snapshot as JSON after every event: {"type":"state","game":"liars-dice","seats":[{slot,seat,name,points,score,wins,losses,hand,revealed,acting,say,notes}],"order":[table position -> slot],"mode":"dice|poker","faces":int,"lowFace":int,"handSize":int,"totalSymbols":int,"talk":bool,"deal":int,"deals":int,"dealsPlayed":int,"opener":slot,"turn":table position,"bid":{seat,quantity,face}|null,"bids":[{seat,quantity,face}],"resolution":{challenger,bidder,quantity,face,actual,counts,bidderWins,forced}|null,"phase":"bidding|reveal|between|done","gameDone":bool,"reason":str,"policyNames":[...],"events":[...],"started":bool,"done":bool,"connected":[bool]}. `seat` is the table position and `slot` the config index; every index in an event is a slot. The events array is append-only and carries the complete transcript: kind `start`; `deal` with {deal, opener, hands} (every seat's hand); `bid` with {deal, seat, quantity, face, scripted, fallback, say, notes}; `challenge` with {deal, seat (challenger), other (bidder), quantity, face, actual, counts, bidderWins, forced, scripted, fallback, say, notes}; and `end` with {deal (deals played), text (the reason)}. The browser page at /client/global renders the stage and /client/replay plays a recorded episode, while the static replay-viewer bundle renders the replays the platform hosts (index.html?replay=<url>) - a wasm build of the same Nim sim, which re-derives every frame from the recorded events in the browser.
