# Infinite Blocks Rules

Infinite Blocks is a shared falling-blocks game. Each player controls one active piece on the same board. Pieces fall over time, can move left or right, can rotate, and can be dropped faster. When a piece settles, it becomes part of the shared stack.

A run of eight filled cells in a row clears after a short flash. Cleared rows can disconnect blocks above them. Unsupported blocks fall, and those falls can create additional clearing cascades. Scores are awarded to the player whose placement caused the clear chain.

The objective is to place blocks cleanly, create flat low stacks, avoid trapped gaps, and score by causing line clears.
