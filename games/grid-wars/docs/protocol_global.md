Global spectators connect a websocket to /global and receive the full snapshot as JSON after every event. The snapshot is one FRAME of the same shape the replay viewer reads, plus the transcript: {"type":"state","game":"grid-wars","seats":[{name,seat,color,id,score,raw,tiles,peakTiles,energy,alive,x,y,idle,kills,selfKills,line,action,banner,deathCause,faultLine,faultText,origin,scriptLines,pending} x4 by seat],"grid":"900 chars, row-major, '.' unclaimed and '1'..'4' owner" (or "gridDelta":[[cell,"c"]] on a non-keyframe frame),"bombs":[{x,y,fuse,seat}],"corpses":[[x,y]],"blast":[[x,y]] (the cells detonating on THIS frame),"round":int,"rounds":int,"tick":int,"ticks":int,"roundsPlayed":int,"phase":"submit|battle|roundEnd|done","focus":seat,"scripts":[[line] x4],"series":[[{raw,tiles,kills,alive,roundScore} x4] x rounds],"log":[str],"gameDone":bool,"reason":str,"policyNames":[4],"events":[...],"started":bool,"done":bool,"connected":[bool]}. The events array is append-only and carries the complete transcript in five kinds: start; round (round, seed - the server-side RNG, logged - spawn, ticks); submit (round, seat, script, lines, origin llm|retry|fallback|scripted, compileError, banner, scripted, text = the seat's notes); battle (round, ticksPlayed, reason horizon|lastStanding|wipeout, stats x4, curve x4, digest); end (round = rounds played, text = complete|deadline). The per-tick history is NOT in the log: it is re-derived from the round seed, the spawn permutation and the scripts by the same Nim sim the server runs, and the recorded digest proves the re-derivation. The browser page at /client/global renders the arena live; a recorded episode is played ONLY by the STATIC replay viewer bundle, which the platform serves for hosted replays (index.html?replay=<url>) -- this game ships no replay pod route.
