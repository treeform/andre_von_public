Global spectators connect a websocket to /global and receive paintbot's binary sprite protocol: one zoomable map layer (1152x672) whose background ships once as static horizontal bands, plus one object per source, ground fruit, cog, alias label and effect. The broadcast chrome (scorebug, clock, scrubber, roster, per-tick events, the score series, the beat timeline and the appended `secret` block that reveals the child's preference to SPECTATORS) rides the same binary channel as the LABEL of the reserved 1x1 sprite id 4090 -- the only channel that survives a hosted replay.

GET /client/global serves the broadcast page. Replays are a STATIC file plus a browser wasm viewer, never a pod: the platform serves the bundle at /v2/coworlds/replays/static/<cow_id>/<sha>/index.html?replay=<s3 url> and the viewer decodes the recorded state -- names, policy names, roles, the full yard geometry, every rule constant, the seed, the child's secret preference, per-tick state, the score and guess series, beats, events and results all live in the replay bytes.
