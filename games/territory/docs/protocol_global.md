Read-only spectator `ServerMessage` stream: one `lobby` roster frame (seat → the REAL policy/player name, which the agents never saw), then per turn a full `snapshot` (the complete tile array plus every seat's public state) and the turn's events. The event vocabulary is exactly: order, rejected, talk, raze, salvage, struck, claim, smear, voided, transfer, income, dried, recovered, eliminated, endcard — and `endcard` carries {reason, turnsPlayed, scores, walls, destroyed, poolStart, poolEnd, warsStarted} so the final panel needs no derivation. Every turn contributes at least one full snapshot, so a viewer re-derives each frame with no server and no interpolation. The saved replay is `{"protocol":"cogweb.replay.v1", frames, players, config, results, usage}`. Spectators send nothing.
